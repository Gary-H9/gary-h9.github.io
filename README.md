# Gary H9

A minimal, paper-like digital space.

## About

This is a clean, distraction-free place for thoughts, projects, and ideas. Designed to feel like reading paper—minimal, focused, and comfortable.

## Features

- 📄 **Paper-like design** — off-white background and serif typography for a natural reading experience
- ⚡ **Fast & minimal** — no bloat, no scripts, pure HTML and CSS
- 🎨 **Built with Pico CSS** — classless CSS framework for elegant simplicity
- 🔗 **GitHub Pages hosted** — automatically published and updated

## Viewing

Visit the site: [https://Gary-H9.github.io/gary-h9/](https://Gary-H9.github.io/gary-h9/)

## Development

To customize this site:

1. Edit `index.html` for structure and content
2. Modify the `<style>` section in `index.html` to adjust colors and fonts
3. Push changes to the `gh-pages` branch
4. Your changes will be live in seconds

## Customization

- **Background color:** Change `--background-color` in the CSS
- **Typography:** Adjust font families in the `body` and heading styles
- **Max width:** Modify the `max-width` in the `main` selector
- **Colors:** Update the CSS variables in `:root`
